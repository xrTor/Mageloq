# Mageloq

**Mageloq** is a lightweight, standalone media gallery engine built for performance and portability. Designed as a "Clean Core" system with zero external dependencies, it provides a robust solution for developers and creators to manage and showcase thousands of media files with zero friction.

### 🚀 Key Features
* **Standalone Architecture:** Zero dependencies. No frameworks, no vendor bloat.
* **Batch Processing:** Optimized engine for handling mass uploads and large-scale media organization.
* **High Performance:** Built on a clean core to minimize server overhead.
* **Responsive UI:** Supports drag-and-drop, fast ZIP downloads, and is fully mobile-optimized.
* **Security:** Hardened file management with strict data sanitization.

### 🛠 Tech Stack
* **Backend:** Native PHP (Core-driven logic)
* **Frontend:** Vanilla JavaScript & CSS (No external libraries)
* **Database:** Modular MySQL schema

### 📦 Quick Start
1. **Clone the repo:** `git clone https://github.com/yourusername/mageloq.git`
2. **Setup DB:** Import the `database.sql` file into your MySQL database.
3. **Configure:** Update your database credentials in `config.php`.
4. **Deploy:** Upload to any PHP-enabled environment.

### 💡 Why Mageloq?
Most gallery solutions are bloated with unnecessary dependencies. Mageloq was built to solve the "Over-Engineering" problem—focusing solely on core requirements to ensure maximum speed and stability.
